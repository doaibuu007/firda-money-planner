## Daftar Temuan Bernomor

### [1] Modal Dialogs Missing Escape Key Listener
- **Prioritas:** HIGH
- **Aturan:** R-32 (Keyboard Accessibility)
- **Lokasi:** `src/components/TransactionModal.jsx`, `src/components/BudgetModal.jsx`, `src/components/CategoryModal.jsx`, `src/components/BackupModal.jsx`, `src/components/IosGuideModal.jsx`
- **Alasan:** Modal dialog tidak dapat ditutup menggunakan tombol keyboard `Escape`.
- **Rekomendasi Perbaikan:** Pasang listener event `keydown` pada setiap modal untuk menangani penekanan tombol `Escape`.

### [2] Form Controls & Icon Buttons Missing Accessible Names
- **Prioritas:** HIGH
- **Aturan:** R-39 (Accessible Semantics & Interaction Affordances)
- **Lokasi:** `src/components/TransactionList.jsx`, `src/components/CategoryModal.jsx`
- **Alasan:** Input pencarian, dropdown filter kategori/waktu/urutan, serta tombol warna tidak memiliki `aria-label` yang dapat diakses oleh screen reader.
- **Rekomendasi Perbaikan:** Tambahkan `aria-label` deskriptif pada elemen `<input>`, `<select>`, dan tombol warna.

### [3] Global Interactive Elements Missing Base Cursor Pointer
- **Prioritas:** HIGH
- **Aturan:** R-39 (Accessible Semantics & Interaction Affordances)
- **Lokasi:** `src/index.css`
- **Alasan:** Aturan `cursor: pointer` belum didefinisikan secara global pada layer CSS dasar untuk seluruh kontrol interaktif.
- **Rekomendasi Perbaikan:** Tambahkan aturan `button, a[href], select, label[for] { cursor: pointer; }` di `@layer base`.

### [4] Low Contrast Text on Light & Dark Backgrounds
- **Prioritas:** HIGH
- **Aturan:** R-25 (Color Contrast)
- **Lokasi:** `src/components/TransactionList.jsx`, `src/components/BudgetOverview.jsx`, `src/components/AnalyticsView.jsx`
- **Alasan:** Teks sekunder memakai `text-gray-400` dengan rasio kontras ~2.8:1 yang gagal memenuhi standar minimum WCAG AA (4.5:1).
- **Rekomendasi Perbaikan:** Naikkan tingkat kontras teks sekunder menjadi `text-gray-600 dark:text-pink-300` agar terbaca tajam dan nyaman.

### [5] Missing Explicit Width and Height on QR Code Images
- **Prioritas:** HIGH
- **Aturan:** R-40 (Performance Mechanisms)
- **Lokasi:** `src/App.jsx`, `src/components/IosGuideModal.jsx`
- **Alasan:** Elemen `<img>` kode QR tidak menetapkan atribut `width` dan `height` eksplisit sehingga berisiko memicu Cumulative Layout Shift (CLS).
- **Rekomendasi Perbaikan:** Tambahkan atribut `width="144"` dan `height="144"` pada tag `<img>`.

### [6] Uncontrolled Infinite Pulse Motion without Reduced-Motion Support
- **Prioritas:** HIGH
- **Aturan:** R-39 (Accessible Semantics & Interaction Affordances)
- **Lokasi:** `src/components/Navbar.jsx`, `src/App.jsx`, `src/index.css`
- **Alasan:** Animasi `animate-pulse` berjalan tanpa henti tanpa opsi penghentian untuk pengguna dengan preferensi `prefers-reduced-motion`.
- **Rekomendasi Perbaikan:** Tambahkan media query `@media (prefers-reduced-motion: reduce) { * { animation: none !important; } }` di `src/index.css`.

### [7] Excessive Glassmorphism / Backdrop-Filter Stacking
- **Prioritas:** MEDIUM
- **Aturan:** R-10 (Glassmorphism Dose Cap)
- **Lokasi:** `src/components/Navbar.jsx`, `src/components/BottomNav.jsx`, `src/components/SummaryCards.jsx`, `src/App.jsx`
- **Alasan:** Efek `backdrop-filter: blur` menumpuk di terlalu banyak komponen sekaligus (navbar, tab bar bawah, kartu saldo, modal, dan footer).
- **Rekomendasi Perbaikan:** Terapkan efek blur hanya pada navbar/bottom tab bar yang melayang, sementara kartu konten dan footer menggunakan latar warna solid.

### [8] Gratuitous "Sparkles" AI Telltale Icons
- **Prioritas:** MEDIUM
- **Aturan:** R-04 (Icons Relevant to Content)
- **Lokasi:** `src/components/Navbar.jsx`, `src/components/AnalyticsView.jsx`, `src/components/TransactionModal.jsx`, `src/App.jsx`
- **Alasan:** Ikon bintang/sparkle digunakan berulang kali sebagai ornamen generik tanpa fungsi finansial yang spesifik.
- **Rekomendasi Perbaikan:** Hapus ikon sparkle yang bersifat murni dekoratif dan ganti dengan ikon fungsional yang bermakna.

### [9] Redundant Capsule Badge in Header
- **Prioritas:** MEDIUM
- **Aturan:** R-09 (Badges with Functional Purpose)
- **Lokasi:** `src/components/Navbar.jsx`
- **Alasan:** Badge kapsul "Daily" di samping judul merupakan elemen dekoratif tanpa fungsi status yang riil.
- **Rekomendasi Perbaikan:** Sederhanakan branding header dengan meniadakan badge kapsul redundan tersebut.

### [10] Uniform Pill/Large Border Radius on All Input Fields
- **Prioritas:** LOW
- **Aturan:** R-11 (Border Radius Consistency & Hierarchy)
- **Lokasi:** `src/components/TransactionModal.jsx`, `src/components/TransactionList.jsx`, `src/components/CategoryModal.jsx`
- **Alasan:** Kolom input formulir menggunakan bentuk kapsul (`rounded-2xl`) yang mengaburkan batas visual antara elemen input dan kartu kontainer.
- **Rekomendasi Perbaikan:** Bedakan hierarki radius: terapkan `rounded-xl` pada kolom isian formulir agar lebih terstruktur dan ergonomis.

### [11] Dark Mode Donut Chart Track Background Discordance
- **Prioritas:** LOW
- **Aturan:** R-34 (Every Theme You Ship Must Work)
- **Lokasi:** `src/components/AnalyticsView.jsx`
- **Alasan:** Lingkaran lintasan donut chart memakai warna statis `#fce7f3` yang terlalu terang dan kontras pada mode gelap.
- **Rekomendasi Perbaikan:** Buat warna lintasan chart adaptif terhadap mode gelap (`#3b1828` pada tema gelap).
